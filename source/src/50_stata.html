Common trap: missing values

Stata treats a missing value as larger than any number, so unemplrate>=8 also flags missing rows. Exclude them explicitly:

gen highun = (unemplrate>=8 & unemplrate~=.)

Do-file skeleton

/* Project: what this is about   */
/* Purpose: what this file does  */
/* Author and date               */

version 15
capture log close
cd "/path/to/working/folder"
log using "output.log", replace
clear all
set more off

use "MyDataSet.dta"

* data preparation and analysis here

log close

Comment with * or wrap text in /* */. The goal is a do-file that reproduces the whole analysis, so someone else (or future you) can rerun it.
